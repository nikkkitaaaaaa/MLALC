    📐 Module 4 — QR Decomposition Engine

    "LU solves exact systems. QR solves the impossible ones — when there are more equations than unknowns."

    🎓 Mathematical Foundation

    QR Decomposition factors any matrix A (m×n) into: - Q — orthogonal matrix (m×m): columns are perpendicular unit vectors, QᵀQ = I - R — upper triangular matrix (m×n)

    Such that: A = QR

    Why do we need this?

    Least squares problem: You have 100 data points but only 3 parameters. That's 100 equations, 3 unknowns — overdetermined. No exact solution exists. But we can find x that minimizes ‖Ax - b‖².

    The answer: x = (AᵀA)⁻¹Aᵀb ... but computing that is numerically terrible. QR gives us the same answer, stably:

    A = QR
Ax = b  →  QRx = b  →  Rx = Qᵀb  (since Qᵀ = Q⁻¹ for orthogonal Q)
    Then back-substitute through R. Clean, stable, elegant. ✨

    🔍 Behind The Algorithm — Householder Reflections

    Why Householder and not Gram-Schmidt?

    Gram-Schmidt orthogonalization suffers from catastrophic cancellation for nearly-dependent columns. Householder reflections are numerically stable by design.

    The idea: A Householder reflection is a matrix H = I - 2vvᵀ that reflects a vector across the hyperplane perpendicular to v. We choose v so that Hx = αe₁ (maps any vector to a multiple of the first basis vector).

    Before:  x = [3, 4, 0]ᵀ   (‖x‖ = 5)
After:   Hx = [-5, 0, 0]ᵀ  ← zeroed everything below first element

    Apply this to each column of A, left-multiplying by H each time. The result is R (upper triangular). Q accumulates the product of all H matrices.

    🧠 Householder Visualized

    Iteration k=0: Zero everything below row 0 in column 0
  [* * * *]        [* * * *]
  [* * * *]   →    [0 * * *]
  [* * * *]        [0 * * *]
  [* * * *]        [0 * * *]

Iteration k=1: Zero everything below row 1 in column 1
  [* * * *]        [* * * *]
  [0 * * *]   →    [0 * * *]
  [0 * * *]        [0 0 * *]
  [0 * * *]        [0 0 * *]

... until R is upper triangular ✅

    🔍 Code Walkthrough

    // Extract column k of R from row k downward
for(int i = 0; i < size; i++)
    x[i] = r_data[(k+i) * n + k];

double alpha = (x[0] >= 0) ? -normx : normx;  // sign trick!

    Why the sign trick? We want v = x - α·e₁ to have large norm (good numerics). Choosing α to have opposite sign to x[0] maximizes ‖v‖, avoiding cancellation. Classic Numerical Recipes move. 🧙

    // Apply Householder to R
for(int j = k; j < n; j++) {
    double dot = 0.0;
    for(int i = 0; i < size; i++)
        dot += v[i] * r_data[(k+i)*n + j];
    double factor = 2.0 * dot;
    for(int i = 0; i < size; i++)
        r_data[(k+i)*n + j] -= factor * v[i];
}

    This applies R ← (I - 2vvᵀ)R efficiently without ever forming the full Householder matrix. Forming H explicitly would waste O(m²) memory and O(m³) flops per step.

    ⚡ Optimization Journey

    Memory reuse: Vectors x and v are allocated once (malloc before the loop) and reused every iteration. No per-iteration allocation → no per-iteration malloc/free overhead.

    Avoiding explicit H: The naive approach forms the full H = I - 2vvᵀ matrix (m×m) then multiplies. Instead, the code applies the rank-1 update R ← R - 2v(vᵀR) directly, reducing the cost from O(m³) to O(m²) per step.

    Complexity: O(mn²) for m≥n — much cheaper than the O(n³) LU when m >> n (tall matrices).

    🧙 Numerical Recipes Wisdom

    "When in doubt, use QR. It is the Swiss Army knife of matrix decompositions."

    • More numerically stable than LU for ill-conditioned systems
    • Works on rectangular (non-square) matrices
    • Foundation of the QR algorithm for eigenvalues
    • Used in MATLAB's \ operator for overdetermined systems

    The sign convention alpha = (x[0] >= 0) ? -normx : normx is straight from Golub & Van Loan's Matrix Computations — the authoritative reference for numerical linear algebra. This library gets it right.
