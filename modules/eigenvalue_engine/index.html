    🌀 Module 5 — Eigenvalue Engine

    "An eigenvector is a vector so well-aligned with a matrix that it only gets scaled, never rotated."

    🎓 Mathematical Foundation

    Definition: For a square matrix A, if Av = λv, then: - v is an eigenvector (a special direction) - λ is the eigenvalue (the stretch/shrink factor)

    A         v         =  λ    v
[3  1] × [1]        =  4 × [1]
[0  4]   [1]              [1]

Check: [3×1 + 1×1] = [4]  ✅  (4 times the original vector)
       [0×1 + 4×1] = [4]

    Why do we care?

    Application Role of Eigenvalues
    🤖 PCA (dimensionality reduction) Directions of maximum variance
    📡 Vibration analysis Natural frequencies of a structure
    🌐 Google PageRank Dominant eigenvector of the web graph
    🔬 Quantum mechanics Observable energy levels
    📊 Markov chains Long-run steady-state distribution

    🔍 Behind The Algorithm — Power Method

    Big idea: Start with a random vector. Multiply by A repeatedly. The component along the dominant eigenvector grows fastest and takes over.

    x₀ = random unit vector

x₁ = Ax₀ / ‖Ax₀‖    ← normalize to prevent blow-up
x₂ = Ax₁ / ‖Ax₁‖
...
xₖ → dominant eigenvector  (as k → ∞)
λ  ≈ xₖᵀ · Axₖ             ← Rayleigh quotient

    Convergence rate: Proportional to |λ₁/λ₂| — the ratio of the largest to second-largest eigenvalue. If they're far apart, it converges in ~10 iterations. If close, it may need hundreds.

    🧠 Geometric Interpretation

    Imagine A stretches space in multiple directions:
  - Direction v₁ stretched by factor λ₁ = 5.0  (dominant)
  - Direction v₂ stretched by factor λ₂ = 1.2
  - Direction v₃ stretched by factor λ₃ = 0.3

Start with random x = [a·v₁ + b·v₂ + c·v₃]

After 1 multiply:  [5a·v₁ + 1.2b·v₂ + 0.3c·v₃]
After 2 multiplies: [25a·v₁ + 1.44b·v₂ + 0.09c·v₃]
After k multiplies: [5ᵏa·v₁ + 1.2ᵏb·v₂ + 0.3ᵏc·v₃]

The v₁ component dominates exponentially. After normalization: x → v₁ ✅

    🔍 Code Walkthrough

    // Initialize: all ones, then normalize
for(int i = 0; i < n; i++) x[i] = 1.0;
normalize(x, n);

for(int iter = 0; iter < max_iter; iter++) {
    mat_vec_mul(a, x, y);          // y = Ax
    lambda_new = dot_product(x, y, n);  // λ ≈ xᵀAx (Rayleigh quotient)
    normalize(y, n);               // y = y/‖y‖

    double diff = fabs(lambda_new - lambda_old);
    for(int i = 0; i < n; i++) x[i] = y[i];  // x ← y

    if(diff < tol) break;          // converged!
    lambda_old = lambda_new;
}

    The Rayleigh quotient λ = xᵀAx is computed using the current x and y=Ax that we already computed — free extra precision with no extra work. It converges to λ twice as fast as the vector itself.

    mat_vec_mul — the inner workhorse: 

    for(int i = 0; i < n; i++) {
    double sum = 0.0;
    for(int j = 0; j < n; j++)
        sum += a->data[i*n + j] * x[j];  // row i · x
    y[i] = sum;
}
    Row-major access on A, sequential access on x — cache-friendly. Each iteration costs O(n²).

    ⚡ Optimization Journey

    Two vectors, not one: x holds the current estimate; y receives Ax. After normalizing y, we copy y→x. Using two separate buffers avoids in-place update aliasing issues.

    Early termination: if(diff < tol) break — stops as soon as the eigenvalue estimate stabilizes. For well-separated eigenvalues, this triggers after ~10-20 iterations rather than running all max_iter iterations.

    Complexity: O(n²) per iteration × iterations. Compare to full eigendecomposition: O(n³). For finding just the largest eigenvalue, Power Method wins hands-down.

    😂 Meme Explanation

    Everyone: "Find all eigenvalues of this 1000×1000 matrix"
Full eigendecomposition: "Sure, that's O(n³) = 10⁹ operations"
Power Method: "I only need the biggest one though"
Power Method: "Hold on let me just... multiply by A a few times"
Power Method: "Done. 20 iterations × O(n²) = 2×10⁷ operations"
Everyone: "50x faster and you only needed one eigenvalue??"
Power Method: "That's literally my whole thing 😎"

    🧙 Numerical Recipes Wisdom

    "The Power Method is stupid simple and often exactly what you need."

    Limitations to know: - Only finds the dominant eigenvalue (largest |λ|) - Fails if two eigenvalues have the same magnitude - Slow if |λ₁/λ₂| is close to 1

    For production: use LAPACK's dsyev (symmetric) or dgeev (general). But for learning, building PageRank, or finding the spectral radius — Power Method is perfect.

    The convergence check fabs(lambda_new - lambda_old) < tol is correct and sufficient. A typical tol of 1e-9 gives 9 digits of accuracy. This implementation is textbook-clean. ✅
